Ex.2
1.ชื่อ thread มีจำนวนเพื่มขึ้นตามจำนวน object ที่สร้าง

2.เมื่อใช้ thread.sleep(2000) thread จะใช้เวลา 2000 มิลลิวินาทีในการทำงานแล้วสลับไป thread อื่น แล้ว thread ไหนเสร็จก่อนจะแสดงผลก่อน แต่เมื่อใช้ 
Math.random(3000)  thread จะใช้เวลาในการทำงานแบบสุ่มตั้งแต่ 0-3000 ทำให้ thread แสดงผลออกมาไม่เหมือนกัน

3.เมื่อลองเปลี่ยนเป็น run() แสดงผลออกมาจะเป็นการทำงานทีละ thread ให้เสร็จก่อนจะไปทำ thread ต่อไป

4.ใช้ run() main จะแสดงผลหลังจบชงเสร็จ แต่ใช้ start() main จะแสดงผลก่อนชง

5.ใช้ Synchronized เมื่อรันออกมาจะแสดงผลโดยจะล็อก ทำงานทีละ Thread แต่ ใช้ AtomicInteger จะไม่ล็อก Thread ทำงานสลับพร้อมกันได้
